## 1. Agreed destination, not a newly invented scope

The immediate approved milestone is a **locally operable, release-qualified Trainer Desk v3.0.0**, still loopback-only and single-Trainer, consolidating the four legacy trackers into a coherent catalog, provenance-aware reference, scenario/career recorder, deterministic Advisor, optional read-only AI Advisor, team/roster workspace, veteran library, and Local API. The v3 exit requires preserved Trainer data, accessible and usable UI, all critical write/read-back paths, trustworthy provenance/absence, passed or explicitly classified test gates, clean-clone install and artwork handling, and an owner-authorized tag. NativePHP Windows packaging is a documented release/acceptance track; the order of packaging versus owner tagging needs explicit reconciliation because the roadmap contains both post-tag sequencing and package-inclusive definition-of-done language.

The **later 1.0.0 gate** is *not synonymous with the v3.0.0 tag*: the four remaining PRD question dispositions must close, `/api/v1` response shapes must be declared in `ARCHITECTURE.md`, and no unresolved defect may affect API/schema. These are post-v3 or separately approved release requirements. There is no mandate for public deployment, login, multi-user, simulations, race-win predictions, an autonomous game player, new storage engines, or new paid AI providers.

Authorities: [`PRD.md`](https://github.com/IzzatFirdaus/umamusume-laravel13/blob/master/PRD.md), [`AGENTS.md`](https://github.com/IzzatFirdaus/umamusume-laravel13/blob/master/AGENTS.md), [`VERSION.md`](https://github.com/IzzatFirdaus/umamusume-laravel13/blob/master/VERSION.md), and the five canonical roadmaps: [Product](https://github.com/IzzatFirdaus/umamusume-laravel13/blob/master/docs/roadmap/PRODUCT-AND-CAPABILITY-ROADMAP.md), [Frontend](https://github.com/IzzatFirdaus/umamusume-laravel13/blob/master/docs/roadmap/FRONTEND-AND-UX-ROADMAP.md), [Quality](https://github.com/IzzatFirdaus/umamusume-laravel13/blob/master/docs/roadmap/QUALITY-AND-VERIFICATION-ROADMAP.md), [Release](https://github.com/IzzatFirdaus/umamusume-laravel13/blob/master/docs/roadmap/V3-RELEASE-ROADMAP.md), [Decisions](https://github.com/IzzatFirdaus/umamusume-laravel13/blob/master/docs/roadmap/DECISIONS-AND-DEPENDENCIES.md).
