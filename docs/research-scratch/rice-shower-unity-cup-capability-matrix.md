# Rice Shower Unity Cup — capability matrix

This matrix records what the Trainer Desk implementation currently supports for a regression suite grounded in `[Rosy_Dreams]Rice_Shower_Unity-Cup.md`. It is built from inspection of the repository, not from the source game.

## Unsupported flows (documented, not tested)

*   **November event reward tier.** The report flags a live disagreement over whether Extreme Spirit Bursts count toward the gold Burning Spirit tier. The repository has no domain rule or UI for this event, so the suite asserts the absence rather than picking an interpretation.
*   **Unity Cup finals simulation.** The finals are described in the scenario config and the Unity Cup panel, but there is no race-simulation or finals-entry UI to exercise.
*   **Skill purchasing / hint discounts.** The report's SP costs and hint-discount ladder are not modelled in application code. The Skills Planner states explicitly that hint discounts are not modelled.
*   **Team rank, burst counters, roster.** The Unity Cup panel renders these as named absences. No write path exists, so the regression suite only verifies the panel's honest refusal to invent values.
