## Rules (from roadmap laws)

- Verify the premise before editing; every file:line is a hypothesis until read.
- One finding = one commit, explicit pathspecs, `-F` message; never `git add -A`; never commit from the real index with peer-dirty files.
- Protected SHAs never amended: `9c99aeaa`, `133e61bc`, `8aff0d83`, `86d649d3`, `24b0aba4`, `abfd1e5f`, `5869d1a0`, `8ef841fb`.
- Peer file mtime < 5 min → skip slice, log it.
- "Stale" is a valid, successful outcome — record evidence, commit nothing.
