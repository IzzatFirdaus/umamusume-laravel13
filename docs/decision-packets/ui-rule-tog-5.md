## Rule Context

## Rule Statement
**TOG-5: Error message clarity** — All error messages must be clear, actionable, and specify the exact problem and required corrective action. Vague, cryptic, or non-actionable error messages violate TOG-5.

**Rationale**: Users must be able to understand error messages and take specific corrective action. Error messages that are vague, cryptic, or lack actionable guidance are a violation of this house rule.
