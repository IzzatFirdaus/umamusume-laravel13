# Decision Packet — House Rule: Target Size 44px (Exceeds WCAG 24px)

## Rule Identifier
**Code**: Target size (house rule) / WCAG 2.5.8 AA
**Source**: `wcag-2.2-accessibility-2026-10-21.md`; Fitts principle in repository; `design-framework-index-2026-10-21.md:84`

## Rule Statement
**WCAG 2.5.8 AA** requires a minimum target size of **24×24 px**.

**Repository House Rule**: The repository requires a **44×44 px** minimum target size, exceeding the WCAG AA standard.

**Rationale**: The 44px rule is a **house rule exceeding the standard**, not conformance to 2.5.8. It should never be described as 2.5.8 compliance. The repository's rule is the Fitts-derived target size; it exceeds the WCAG minimum for tactile accessibility.

## Applied Screens
This ruling governs touch target sizing in the repository, where 44×44 px is the minimum despite WCAG AA's 24×24 px requirement.

## Verdict
**House rule exceeds WCAG AA**: The repository's 44px target size standard exceeds the WCAG 2.5.8 AA minimum of 24px; neither is conformance to the other; the 44px rule is the repository's house rule for tactile accessibility.
