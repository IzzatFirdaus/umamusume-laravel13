Annotation key · Races

  1. The band column is derived and marked. A race's band is its distance read through the published edges; where those edges conflict, the cell carries an asterisk and a note rather than a silent choice.
  2. Payout by grade, first place only. The two published career families differ, so both are stated instead of one being averaged.
  3. Fan thresholds are blank where the catalog has none. Some rows genuinely carry no gate; printing 0 would invent one.
  4. Closure (uilaws) requires a derived value to show where it came from. The band column is computed from distance, so the screen labels it as derived. A derived cell presented as a stored fact closes a gap the reader was never shown.
  5. Heuristic coverage. H1. The derived band says it is derived, so the system’s own inference is visible as an inference.
  6. Framework coverage. Gerhardt-Powals 2 on reducing uncertainty and Information architecture 4 on exemplars. The derived band says it is derived, and the row shows the distance the band was read from.
