Annotation key · Veteran comparison

  1. Differences are a column. The comparison states "same" or what changed; the row tint only draws the eye. That is Von Restorff used for scanning rather than for decoration.
  2. The most useful difference is explained in prose. Two blue factors on different stats read as similar in a table and mean something quite different; the note says which.
  3. "Nothing decisive" is a permitted verdict. A comparison that can only produce winners is a recommendation engine. Stating that a record has no decisive trait is the honest third answer.
  4. Matching rows still print. Hiding them would make a Trainer wonder whether the property was compared at all.
