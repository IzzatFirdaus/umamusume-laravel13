Annotation key · Veteran comparison

  1. Differences are a column. The comparison states "same" or what changed; the row tint only draws the eye. That is Von Restorff used for scanning rather than for decoration.
  2. The most useful difference is explained in prose. Two blue factors on different stats read as similar in a table and mean something quite different; the note says which.
  3. "Nothing decisive" is a permitted verdict. A comparison that can only produce winners is a recommendation engine. Stating that a record has no decisive trait is the honest third answer.
  4. Matching rows still print. Hiding them would make a Trainer wonder whether the property was compared at all.
  5. Heuristic coverage. H8. Three columns, one fact per row, nothing that does not change the comparison.
  6. Framework coverage. Gerhardt-Powals 8 on only what is needed and Information architecture 6 on multiple classification. Three columns, one fact per row, nothing that does not change the comparison.
  8. The rail collapses, and the word never leaves the DOM. The app can collapse its global navigation to marks instead of words, and this set does the same (AppLayout.vue:191-233). A collapsed destination moves its label to sr-only and gains a title, so it keeps its accessible name; the active one keeps aria-current="page" and a left rule, so state never rides on colour alone. The control is in the top bar because the bar is the one row present at every width. The choice is localStorage, not a Preference row, because Preference::KEYS is exactly theme and failure_estimate.
