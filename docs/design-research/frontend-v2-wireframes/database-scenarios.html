Annotation key · Scenarios

  1. Bold marks the outlier, not the maximum. Every row has one stat that differs; making it bold lets a Trainer read four scenarios' identity in one glance.
  2. Panels are a matrix, not prose. Four columns of on/off is the composition contract itself, and printing it makes the cockpit's behaviour explainable.
  3. Ruleset date is separated from version. They are two facts; merging them would invent a version number no source defines.
  4. Selective Attention: bold marks the outlier, not the maximum. Every scenario row has exactly one stat that differs, so bolding it is what makes the identity of the scenario scannable. Bolding the highest number would highlight a different fact on every row.
