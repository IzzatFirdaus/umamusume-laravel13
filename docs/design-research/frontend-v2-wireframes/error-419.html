Annotation key · 419

  1. It answers the data-loss question first. "Your last saved turn is unaffected" is the first sentence, because it is the only thing a Trainer cares about at this moment.
  2. It distinguishes saved from unsaved. The table names what survives and what does not, instead of a generic "try again".
  3. It does not auto-retry. Automatically resubmitting a stale form can duplicate a turn; asking a human to reload is the safe path.
  4. One error surface. The page replaces the framework's modal rather than stacking on top of it.
