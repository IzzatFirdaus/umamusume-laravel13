Annotation key · Create a career

  1. The fields are the request's fields. Trainee and status are required; the rest are nullable and accepted by the same store request, so nothing here is a field the app would reject.
  2. Leaving the scenario empty is a real option. It renders the baseline strip; the select carries "Not set (baseline strip)" rather than forcing a scenario that would put wrong widgets on the run page.
  3. One combobox for trainee and costume. The page's only trainee source feeds inheritance parents too, so the two do not drift; a costume-less row writes the trainee alone.
  4. The Grade Point period is entered, never derived. A scenario that does not compose the meter refuses the value with a message rather than silently dropping it.
