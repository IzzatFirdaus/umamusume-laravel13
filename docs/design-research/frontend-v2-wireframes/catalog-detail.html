Annotation key · Trainee detail

  1. The total is guaranteed where the parts are not. 450 / 425 / 400 is a hard invariant in the export, so the screen can print it while leaving per-stat cells blank. That is the difference between an absence and an unknown total.
  2. Growth is per costume, and the page says why. A character-wide growth value cannot exist; stating that prevents a Trainer from hunting for one.
  3. Aptitudes are one row per axis, not one letter per cell. Six strong letters and three weak ones fit in three lines; a nine-cell grid would be the same data at twice the height.
  4. Breakthrough is a three-row table. The +50 per rank rule is the most useful catalogue fact for a Trainer building a factor, and it costs three rows.
  5. Miller’s Law chunks the nine aptitude letters. Turbo/Dirt, then four distances, then four running styles: three families rather than nine undifferentiated grades. The grouping is the client’s own, not a layout convenience.
  6. Heuristic coverage. H6. Nine aptitude letters in three families, so they are read as groups rather than recalled one at a time.
  7. Framework coverage. Gerhardt-Powals 3 on fusing data and Information architecture 6 on multiple classification. The nine aptitude letters are three families of three, and the total is guaranteed where the parts are not.
  9. The rail collapses, and the word never leaves the DOM. The app can collapse its global navigation to marks instead of words, and this set does the same (AppLayout.vue:191-233). A collapsed destination moves its label to sr-only and gains a title, so it keeps its accessible name; the active one keeps aria-current="page" and a left rule, so state never rides on colour alone. The control is at the head of the rail, where DESIGN.md §2.2 puts a control that belongs to a pane: the penalty for a distant control is exactly why the top-bar version was wrong. The choice is localStorage, not a Preference row, because Preference::KEYS is exactly theme and failure_estimate.
  11. The way back to the hub is a strip, not a word in a corner. The breadcrumb linked "Database", but it sits in the top bar on the brand-blue chrome with no underline, so it read as a word rather than as a link and a Trainer looking for the way back found the global rail instead. The nine areas are one family, so they are grouped as one family: a sub-navigation strip of the nine, with the current one marked, and the breadcrumb link now visibly a link. Information Architecture principle 7 (focused navigation) and principle 5 (front doors).
  13. The type is a chip, and the chip is never the mark alone. The client identifies a support card by the chip it wears, so the type column carries the client's own glyphs in the client's own chip colours. The word stays beside the mark, because a mark alone breaks WCAG 1.4.1 and because a stat carries no saturated identity hue (DESIGN-CORPUS.md:371-393): the identity is the glyph plus a whisper of band tint, and the hue is spent on meaning.
  14. The picture slot is a drawing, and absence is a normal state. The app renders a mirrored card_portrait for the form in view at 64px (Catalog/Show.vue, DESIGN.md §4.7), and the index shows the debut form's own portrait instead. A file the mirror does not hold renders nothing — no grey box, no placeholder glyph — and the heading keeps its text. The dashed frame here marks a cell the picture would occupy, and the subject inside it names the picture that belongs there.
  15. The per-stat figures are now on the payload, so the cells no longer state an absence. The earlier read of this screen printed — in every base cell because the live Inertia payload carried the total and not the five values. The catalogue now holds them, so the table prints 96 / 79 / 108 / 69 / 98 for [Starry Nocturne] and the ★4 and ★5 columns beside them, and the five cells sum to 450, 500 and 550 as the total row says. Source: assets/data/umamusume.js, built from the app's own tables.
  16. The costume-form strip is a location control, and the table keeps every form. The strip's ?form= links mark the active form with aria-current="page"; the flat table below still lists every form with the active row marked, and the section below the table reads the active form back. That is the conservative reading of FQ-11: the strip says where you are, the table says what exists, and the two cannot disagree about which form is active.
