Annotation key · Run deck

  1. Six slots always shown. Empty slots are dashed boxes with an add action, so the deck's size is visible rather than inferred from a count in a heading.
  2. Gauge state carries a word. "Gauge 80" and "Not yet orange" rather than a colour alone; the bar is decoration.
  3. Pal cards say "No gauge kit". The absence is the deciding fact, printed on the card.
  4. Save is one action for the whole deck. Per-card writes would be six save verbs, which is the defect the external review counted on the cockpit.
  5. Miller’s Law: six slots always shown. Empty slots are dashed boxes with an add action, so the deck’s size is visible rather than implied. A deck rendered only from what is equipped cannot show how much room is left.
  6. Heuristic coverage. H6. Six slots always shown, empty ones dashed, so the remaining capacity is recognised rather than remembered.
  7. Framework coverage. Norman on signifiers, and Gestalt on closure. Six slots always show, an empty one is a dashed box with an add action rather than an absence, and the dashed border is what tells the Trainer the slot is there.
  9. The rail collapses, and the word never leaves the DOM. The app can collapse its global navigation to marks instead of words, and this set does the same (AppLayout.vue:191-233). A collapsed destination moves its label to sr-only and gains a title, so it keeps its accessible name; the active one keeps aria-current="page" and a left rule, so state never rides on colour alone. The control is in the top bar because the bar is the one row present at every width. The choice is localStorage, not a Preference row, because Preference::KEYS is exactly theme and failure_estimate.
