Annotation key · Support card detail

  1. The stage table is the card. Effect value is a function of limit breaks, so the detail shows the whole ladder in one row rather than five separate cards or a single "current value". That is Chunking applied to a range.
  2. Break state is drawn as the client draws it. Four diamonds, filled per break, with the level readout beside them. Mirroring the client's grammar is Jakob's Law at its most literal.
  3. The duplicate rule is stated where a Trainer would try to break it. "Two identical copies cannot sit in one deck" is on the detail screen, not only in the deck editor's validation.
  4. Where-used is answerable. Runs own their slots, so the same card can appear in several runs without conflict, and the detail says which.
  5. Provenance is a row, and a link. The external review's "get the file paths out of the UI" point: the screen names the source family and links to the ledger, rather than printing .md paths and line numbers.
  6. Heuristic coverage. H4. Effect names are the client’s own strings, so a card reads here exactly as it reads in the client.
  7. Framework coverage. Tognazzini 4 on consistency with user expectation, and Gerhardt-Powals 5 on names related to function. The effect names are the client's own strings, so a card reads here exactly as it reads in game.
  9. The rail collapses, and the word never leaves the DOM. The app can collapse its global navigation to marks instead of words, and this set does the same (AppLayout.vue:191-233). A collapsed destination moves its label to sr-only and gains a title, so it keeps its accessible name; the active one keeps aria-current="page" and a left rule, so state never rides on colour alone. The control is in the top bar because the bar is the one row present at every width. The choice is localStorage, not a Preference row, because Preference::KEYS is exactly theme and failure_estimate.
  11. The way back to the hub is a strip, not a word in a corner. The breadcrumb linked "Database", but it sits in the top bar on the brand-blue chrome with no underline, so it read as a word rather than as a link and a Trainer looking for the way back found the global rail instead. The nine areas are one family, so they are grouped as one family: a sub-navigation strip of the nine, with the current one marked, and the breadcrumb link now visibly a link. Information Architecture principle 7 (focused navigation) and principle 5 (front doors).
