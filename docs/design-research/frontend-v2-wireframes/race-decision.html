Annotation key · Race decision

  1. Blocked rows are visible, not filtered out. The Dirt Dash row is disabled with "Aptitude too low" rather than hidden. Hiding it would leave a Trainer wondering whether the race exists; showing it teaches the aptitude rule.
  2. Aptitude letters sit beside the distance band so the filter's result explains itself. Same chunking as the trainee grid.
  3. Unpublished payouts stay blank. Only 1st place is sourced; 2nd and 3rd cells are empty. Printing an extrapolated "2nd = 60%" would be a fabricated game rule — the exact failure the provenance gates exist to stop.
  4. Where no probability exists, none is invented. URA and Unity Cup publish no consecutive-race table, so the screen shows the count and says why there is no percentage.
  5. "Train instead" is a real escape. A race screen that only offers races forces the decision; the outline button returns to training without losing the turn.
  6. Hick’s Law over Closure: blocked rows stay visible. The Dirt Dash row is disabled with its reason rather than filtered out, because a hidden option reads as an option that does not exist, while a disabled one reads as a rule. The reason is the part that teaches the rule.
