Annotation key · Source ledger

  1. This page replaces file paths in the UI. The external review's point 10: "Source: UMAMUSUME_REFERENCE.md §2.2, docs/scenarios/02-unity-cup.md:28, SCENARIO-PUBLISHER-REFERENCES.md line 568" is a changelog, not an interface. One ledger row and one link does the same job.
  2. Tiers are words in pills. S / A / B / C each get a sentence, so the weight is legible rather than a code.
  3. Conflicts are a first-class section. Four live disagreements are listed with both sides. A ledger that only recorded agreements would be a confident record of things nobody double-checked.
  4. The verification date is stated as verification. "Verified 2026-09-27" is not "updated today".
  5. Mental Model replaces file paths with what the source is. The screen answers which source backs a claim, not where the file lives. A repository path in a user interface describes the build, not the evidence.
  6. Heuristic coverage. H10. Which source backs a claim is the documentation this product needs, delivered where the claim lives rather than in a manual.
  7. Framework coverage. Information architecture 5 on front doors and Gerhardt-Powals 2 on reducing uncertainty. The ledger answers which source backs a claim rather than where the file lives, and every figure carries its tier and date.
  9. The rail collapses, and the word never leaves the DOM. The app can collapse its global navigation to marks instead of words, and this set does the same (AppLayout.vue:191-233). A collapsed destination moves its label to sr-only and gains a title, so it keeps its accessible name; the active one keeps aria-current="page" and a left rule, so state never rides on colour alone. The control is at the head of the rail, where DESIGN.md §2.2 puts a control that belongs to a pane: the penalty for a distant control is exactly why the top-bar version was wrong. The choice is localStorage, not a Preference row, because Preference::KEYS is exactly theme and failure_estimate.
  11. The way back to the hub is a strip, not a word in a corner. The breadcrumb linked "Database", but it sits in the top bar on the brand-blue chrome with no underline, so it read as a word rather than as a link and a Trainer looking for the way back found the global rail instead. The nine areas are one family, so they are grouped as one family: a sub-navigation strip of the nine, with the current one marked, and the breadcrumb link now visibly a link. Information Architecture principle 7 (focused navigation) and principle 5 (front doors).
