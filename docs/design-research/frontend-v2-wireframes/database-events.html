Retry rules

An event choice is final. The Alarm Clock is the game's retry item and it covers goal races whose placing was missed, and a lost Team Race — not an event.

○ A guide narrows the Alarm Clock further: a player may use up to three per run. The catalogue states the item's own limits rather than implying an unbounded undo.

Annotation key · Events

  1. "Effects documented?" is a column. Most events have no published effect table, and saying so per row is more honest than a catalogue that looks complete.
  2. Scenario scoping is explicit. The secret-event row states it does not fire in Trackblazer, which is a real mechanical difference and not a caveat.
  3. Retry rules sit beside the events. A Trainer looking up an event after a bad outcome is exactly who needs to know what can and cannot be undone.
  4. Law of Proximity puts the caveat on the row it qualifies. "Effect not published" sits in the row it applies to rather than in a footnote, because a qualification that travels away from its value stops being read.
  5. Heuristic coverage. H9. "Effect not published" sits in the row it qualifies, so the absence is diagnosed rather than guessed.
  6. Framework coverage. WCAG 1.3.3 on sensory characteristics and Information architecture 4 on exemplars. "Effect not published" sits in the row it qualifies, so the absence is diagnosed rather than guessed, and the published events show their effect.
  8. The rail collapses, and the word never leaves the DOM. The app can collapse its global navigation to marks instead of words, and this set does the same (AppLayout.vue:191-233). A collapsed destination moves its label to sr-only and gains a title, so it keeps its accessible name; the active one keeps aria-current="page" and a left rule, so state never rides on colour alone. The control is in the top bar because the bar is the one row present at every width. The choice is localStorage, not a Preference row, because Preference::KEYS is exactly theme and failure_estimate.
  10. The way back to the hub is a strip, not a word in a corner. The breadcrumb linked "Database", but it sits in the top bar on the brand-blue chrome with no underline, so it read as a word rather than as a link and a Trainer looking for the way back found the global rail instead. The nine areas are one family, so they are grouped as one family: a sub-navigation strip of the nine, with the current one marked, and the breadcrumb link now visibly a link. Information Architecture principle 7 (focused navigation) and principle 5 (front doors).
