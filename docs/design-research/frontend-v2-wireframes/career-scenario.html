Annotation key · Scenario selection

  1. Hick's Law applied as four cards, not a dropdown. Four options is the number where a card grid beats a select: the summaries are long enough that a dropdown would hide the deciding information. Above roughly six, the pattern inverts.
  2. The chosen card is marked three ways — a real radio, a 2px --pick-line border, and the green tint. Colour never carries the state alone (DESIGN.md D-12, WCAG 1.4.1).
  3. Reversibility is stated before the commit. "What changes after this step" is the Paradox of the Active User answered in advance: the page says what a Trainer would otherwise learn by getting it wrong.
  4. Caps are printed as the matrix states them, not collapsed to one number. Unity Cup reads "1300 ×4 · Wit 1800" because Wit is the outlier, and the outlier is the scenario's mechanical identity (UMAMUSUME_REFERENCE.md §2.2.2).
  5. Stepper shows position without hiding steps. Six pills, current one filled, no step removed at a narrow width — the same rule SCREEN-009 §SCR-CAR-011 applies to cockpit regions.
  6. One primary action. "Continue to trainee" is the only filled button; Cancel is an outline.
