Annotation key · Veteran detail

  1. Factors lead. A veteran exists to be inherited from, so the factor table is the first block. Final stats come second because they only matter for a team entry.
  2. Absence is honest. Five final-stat rows state that the payload does not carry them, rather than printing zeros or dropping the block. A zero would look like a real reading of a real run.
  3. The ★4 ceiling is stated where it applies. It bounds a decision (spend a research report or not), so it belongs on the record it constrains.
  4. A record is reusable. "Using it once does not consume it" answers the question a Trainer asks before picking a parent they might want later.
  5. Serial Position decides the order. Factors lead because a veteran exists to be inherited from, and final stats follow. Leading with stats would put the reference data where the deciding data belongs.
  6. Heuristic coverage. H6. Factors lead because they are what the veteran is for, so the inheriting decision reads from visible evidence.
  7. Framework coverage. Information architecture 1 on objects and Shneiderman 8 on short-term memory. Factors lead because a veteran exists to be inherited from, and the deciding values are on the page rather than one screen away.
  9. The rail collapses, and the word never leaves the DOM. The app can collapse its global navigation to marks instead of words, and this set does the same (AppLayout.vue:191-233). A collapsed destination moves its label to sr-only and gains a title, so it keeps its accessible name; the active one keeps aria-current="page" and a left rule, so state never rides on colour alone. The control is in the top bar because the bar is the one row present at every width. The choice is localStorage, not a Preference row, because Preference::KEYS is exactly theme and failure_estimate.
  11. The type is a chip, and the chip is never the mark alone. The client identifies a support card by the chip it wears, so the type column carries the client's own glyphs in the client's own chip colours. The word stays beside the mark, because a mark alone breaks WCAG 1.4.1 and because a stat carries no saturated identity hue (DESIGN-CORPUS.md:371-393): the identity is the glyph plus a whisper of band tint, and the hue is spent on meaning.
