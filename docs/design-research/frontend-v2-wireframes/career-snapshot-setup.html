Annotation key · Snapshot setup

  1. One pass, not a wizard. A Trainer holding a client partway through a career reads this top to bottom once; the run that comes out stands where the client says.
  2. Every state field carries one of three confidences. A typed number is Known, "I don't know this value" is Unknown, and a blank field is Not provided. The review keeps the three apart.
  3. Legacy and deck are linked, not re-entered. Each has one write path already; repeating it here would give the same fact two writers.
  4. The position is entered, not assumed. Year, month and half are the client's own calendar grid, so the run does not pretend to start at turn 1.
