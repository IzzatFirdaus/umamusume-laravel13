Annotation key · Umamusume catalog

  1. Cards, not a table. A trainee is identified by name and three aptitude letters, so a card grid reads faster than a nine-column table at this catalogue size. Above roughly 200 rows with more columns, the pattern inverts back to a table.
  2. Three letters, not nine. Each card shows the strongest value per axis; the detail screen owns the full set. That is the chunking the trainee picker also uses, so the grammar is learned once.
  3. Aptitude never shares a label with a stat grade. The cockpit's stat-grade banding is marked provisional in config; this screen prints aptitudes only, and the lede says so.
  4. Release status is a word. "Global" is a pill with text. The catalog's JP-only case is rendered as a muted label in the running app, and no badge is invented here.
  5. Hick’s Law sets the filter count, not the row count. 71 trainees is long past the point where scanning beats choosing, so the deciding dimensions are filters and the results are cards. A table would add columns without reducing the number of decisions per trainee.
  6. Heuristic coverage. H8. Cards carry name plus three aptitude letters; every further column is behind the detail page, because it does not decide which trainee to open.
  7. Framework coverage. Information architecture 3 on disclosure and 2 on choices. A trainee is identified by name and three aptitude letters, so the card grid reads faster than a table and every further column is behind the detail page.
  9. The rail collapses, and the word never leaves the DOM. The app can collapse its global navigation to marks instead of words, and this set does the same (AppLayout.vue:191-233). A collapsed destination moves its label to sr-only and gains a title, so it keeps its accessible name; the active one keeps aria-current="page" and a left rule, so state never rides on colour alone. The control is in the top bar because the bar is the one row present at every width. The choice is localStorage, not a Preference row, because Preference::KEYS is exactly theme and failure_estimate.
  11. The way back to the hub is a strip, not a word in a corner. The breadcrumb linked "Database", but it sits in the top bar on the brand-blue chrome with no underline, so it read as a word rather than as a link and a Trainer looking for the way back found the global rail instead. The nine areas are one family, so they are grouped as one family: a sub-navigation strip of the nine, with the current one marked, and the breadcrumb link now visibly a link. Information Architecture principle 7 (focused navigation) and principle 5 (front doors).
