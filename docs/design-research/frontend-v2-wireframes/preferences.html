Settings

Preferences

Layout, language, theme and the target defaults a new career starts from. Stored in the database, not the browser.

Layout width

How much horizontal space pages use. Compact is best for forms; Wide is best for tables and grids.

○ The widths are the ratified ones: 768 / 1152 / 1536. Below 1280px the wide shell collapses to the standard breakpoints, so choosing wide on a laptop changes nothing.

Target defaults

What a new career's build-target step starts from. Empty means the step starts blank.

Data

Export everything as JSON Download a backup

Export is a file download. A backup is a complete copy you can restore from.

Theme

Applied to every screen. “Follow the system” stores nothing, so the OS preference decides.

○ This is the app’s only theme control — a three-option choice, not a two-way switch. It is a select in the running Preferences page; it is drawn as radios here so the three options read side by side. There is no per-page switching anywhere else in the product.

Language

Game vocabulary is the client's own English either way; the language setting changes the interface, not the game terms.

Annotation key · Settings

  1. One save model across the screen. One bar, one verb, disabled when clean. The cockpit's seven save verbs in four styles is the defect this avoids.
  2. Layout choices state their widths. "Compact / Standard / Wide" means nothing without 768 / 1152 / 1536, and a Trainer choosing wide on a laptop needs to know it collapses.
  3. Theme is a stored preference with a documented resolution order. No client-side write, which is the rule the app already enforces.
  4. Language and game vocabulary are separated. Switching the interface to Japanese does not translate the client's own terms, because those are proper nouns in the game.
  5. Jakob’s Law for the shape, Occam’s Razor for the verbs. Preferences look like preferences: labelled controls, one save model, a bar that stays disabled while clean. The screen exists because the cockpit shipped seven save verbs in four styles.
  6. Heuristic coverage. H4. One save model across the screen, matching the convention a settings page is expected to follow.
