Annotation key · Skill detail

  1. Engine tokens first, prose second. The condition table is the primary content and the readable sentence is a labelled convenience. Reversing that order would make the screen un-diffable against the export.
  2. The full price ladder is computed and shown. One row per hint level, so a Trainer sees exactly what earning one more hint buys before spending SP on it.
  3. The rounding case is displayed, not hidden. 84.5 floored to 84 is the only rounding observed, and printing it is cheaper than a Trainer filing a bug.
  4. Hints are per-run. The "In your runs" block keeps a run-scoped fact out of a catalogue fact, which is the same separation the cockpit's entered ceiling versus scenario cap needs.
  5. Provenance is a family and a date, with a link. No file paths on screen.
  6. Cognitive Load: the condition table is the primary content. Engine tokens lead and the readable sentence labels them, so the reader recognises the gate instead of recalling what a phase number means. Prose alone would hide the exact boundary the skill fires on.
  7. Heuristic coverage. H6. The condition table is primary and the sentence labels it, so the gate is recognised rather than reconstructed from prose.
  8. Framework coverage. Information architecture 3 on disclosure and Gerhardt-Powals 4 on aids to interpretation. The condition table is primary and the readable sentence labels it, so the gate is recognised rather than reconstructed from prose.
  10. The rail collapses, and the word never leaves the DOM. The app can collapse its global navigation to marks instead of words, and this set does the same (AppLayout.vue:191-233). A collapsed destination moves its label to sr-only and gains a title, so it keeps its accessible name; the active one keeps aria-current="page" and a left rule, so state never rides on colour alone. The control is in the top bar because the bar is the one row present at every width. The choice is localStorage, not a Preference row, because Preference::KEYS is exactly theme and failure_estimate.
  12. The way back to the hub is a strip, not a word in a corner. The breadcrumb linked "Database", but it sits in the top bar on the brand-blue chrome with no underline, so it read as a word rather than as a link and a Trainer looking for the way back found the global rail instead. The nine areas are one family, so they are grouped as one family: a sub-navigation strip of the nine, with the current one marked, and the breadcrumb link now visibly a link. Information Architecture principle 7 (focused navigation) and principle 5 (front doors).
