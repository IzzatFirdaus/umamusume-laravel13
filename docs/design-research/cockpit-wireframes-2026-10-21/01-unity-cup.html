Domain facts added from the scenario references (2026-10-21)

This file is superseded by 05-unity-cup-hfw-v2.html, which carries the same data plus the 12 prototype-driven changes. These five facts come from docs/UMAMUSUME_REFERENCE.md and docs/proposals/Unity-Cup-plan.md and are recorded here so the earlier file is not read as having a complete picture.

  1. Mood is a multiplier. GREAT +20% training yield / +4% pre-race; GOOD +10% / +2%; NORMAL 0%; BAD −10% / −2%; AWFUL −20% / −4%, from the client's own Mood Effect panel (UMAMUSUME_REFERENCE.md §1.1.6). The strip printing a bare "GREAT" hides a fifth of a turn's value.
  2. Rank drives facility level. G/F → Lv 1, D/E → Lv 2, B/C → Lv 3, A → Lv 4, S → Lv 5, matching team_rank_ladder. B and C share a level, so a rank move can cross no level boundary. This run records no team stat ranks, so no level is derivable.
  3. The Team Board is the scenario's permanent fixture (Unity-Cup-plan.md §8a): overall rank, facility progression, five team stat ranks, and race coverage across Sprint / Mile / Medium / Long / Dirt at 3 fielded each.
  4. Advisor priority is not what the page shows. The plan ranks don't-end-run → don't-wreck-run → burst breakpoints (4/7/10/13) → facility levels → training target → optimization, and requires a dual readout of trainee gain against team gain. The page gives the trainee half only.
  5. Burst proximity is a real boundary. This run is at 11 bursts, inside 10–12, one short of the 13 tier. The old Goal-Gradient failure hid exactly that.

Energy below 50 is the published line where failure risk changes character; rest pays +30 (normal), +50 (modal), +70 (big success); Wit costs no Energy and pays +4–5 SP against +2 for the other four (UMAMUSUME_REFERENCE.md §1.1.5–1.1.6).
