# docs/deprecated

Historical records from the legacy Umamusume apps that this repository consolidated.
Nothing here is a specification, a data source, or guidance for current work: each item
is kept because it records what an earlier tool did and why its systems were cut, and
each carries an annotation saying which of its content has been superseded by tracked
material. The review of these three PDFs is `REVIEW-2026-09-30.md` in this folder (kept
untracked pending the owner's Decision 3, so a fresh clone may not carry it); it
states the disposition of each file, its lore findings, and the supersession map. Do not
copy display text out of these PDFs into app copy or documentation.

## Annotations

### `UMAMUSUME RACE PLAN TRACKER (author_ extremerazr).pdf`

> Archive copy. A blank paper recording form from the legacy tracker family; no data, no specification, no extractable content. Retained for historical reference only. Reviewed 2026-09-30: `docs/deprecated/REVIEW-2026-09-30.md` §3A.

### `Uma Musume Career Tracker System Documentation.pdf`

> Historical record of the legacy career-tracker app's documentation set, retained for context on what was built and why its systems were cut. Superseded in every extraction-relevant area: roster by `docs/data/2026-09-29-global-roster-crosscheck.md`, skills by ADR-0011, schema by `ARCHITECTURE.md`. Contains legacy display copy that fails the current C-4 lore gate in two places (page-level; see review §3B). Do not reuse its copy. Reviewed 2026-09-30: `docs/deprecated/REVIEW-2026-09-30.md` §3B.

### `Umamusume Progress Tracker.pdf`

> Archive copy. Support-card reference (subject is a PRD §6.9 non-goal; ADR-0005) plus 17 historical run sheets. No extractable data; retained for the owner's reference. Contains third-party card-tier assessment vocabulary (Game8 tier lists) on its card pages; the subject is CUT and is not to be reused. Reviewed 2026-09-30: `docs/deprecated/REVIEW-2026-09-30.md` §3C.
