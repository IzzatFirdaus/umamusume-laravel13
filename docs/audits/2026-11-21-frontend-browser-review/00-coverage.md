- Detected field errors require a descriptive text association. The GOV.UK pattern supports an error summary with links and consistent inline wording, focus on the summary, and retention of entered values. [Error Identification](https://www.w3.org/WAI/WCAG22/Understanding/error-identification), [GOV.UK Error Summary](https://design-system.service.gov.uk/components/error-summary/), [GOV.UK Validation](https://design-system.service.gov.uk/patterns/validation/)
- Responsive layout guidance supports viewport and overflow checks. Automated scans cover a subset of accessibility issues, so the reported checks are scoped manual observations. [web.dev Responsive design](https://web.dev/articles/responsive-web-design-basics), [Playwright accessibility testing](https://playwright.dev/docs/accessibility-testing)
